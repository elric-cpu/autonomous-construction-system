# Autonomous Construction System

This repository contains the full backend and frontend source code for an autonomous general contracting system. It includes:

- **benson-agentic-system** – a TypeScript/Node multi-agent backend with tasks and agents for lead qualification, scope building, subcontractor search/onboarding, customer onboarding, and more.
- **construction_agentic_system** – a Python CrewAI-based backend using YAML agent/task definitions.
- **horizons** – the front-end built with Hostinger Horizons and React, including a job-request form and contact page integration.

Workflows in `.github/workflows` are set up to run continuous integration and deploy the front-end to GitHub Pages upon pushes to `main`.
